# Person CRUD API

A basic REST API built with **FastAPI** and **PostgreSQL** that supports Create, Read, Update, and Delete (CRUD) operations for person records.

## Features

- Create a person
- Retrieve all persons
- Retrieve a person by ID
- Update a person's details
- Delete a person
- Validate request data using Pydantic
- Test endpoints using Swagger UI

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Psycopg 3
- Pydantic
- Uvicorn
- python-dotenv

## Person Fields

| Field | Description |
|---|---|
| id | Unique identifier generated by PostgreSQL |
| name | Person's name |
| gender | Person's gender |
| age | Person's age |
| dob | Date of birth |
| address | Residential address |
| blood_group | Blood group |
| time_zone | Time zone identifier, such as Asia/Kolkata |

## Setup

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd person_crud
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure PostgreSQL

Create a PostgreSQL database and a user with appropriate permissions.

Create a `.env` file in the project root:

```text
DATABASE_URL=postgresql://person_user:YOUR_PASSWORD@localhost:5432/person_db
```

Replace `YOUR_PASSWORD` with your actual PostgreSQL password.

Do not commit `.env` to GitHub.

### 5. Create the database table

Connect to `person_db` using PostgreSQL and execute:

```sql
CREATE TABLE persons (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    gender VARCHAR(30) NOT NULL,
    age INTEGER NOT NULL,
    dob DATE NOT NULL,
    address TEXT NOT NULL,
    blood_group VARCHAR(5) NOT NULL,
    time_zone VARCHAR(100) NOT NULL
);
```

If the table already exists, do not create it again.

### 6. Run the application

```bash
uvicorn main:app --reload
```

The API runs locally at:

http://127.0.0.1:8000

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Check API status |
| POST | `/persons` | Create a person |
| GET | `/persons` | Retrieve all persons |
| GET | `/persons/{person_id}` | Retrieve one person |
| PUT | `/persons/{person_id}` | Update a person |
| DELETE | `/persons/{person_id}` | Delete a person |

## Test with Swagger UI

Open:

http://127.0.0.1:8000/docs

Use **Try it out** to execute the API endpoints interactively.

### Example request

For `POST /persons`:

```json
{
  "name": "Ananya",
  "gender": "Female",
  "age": 26,
  "dob": "1999-12-05",
  "address": "Bengaluru, Karnataka",
  "blood_group": "O+",
  "time_zone": "Asia/Kolkata"
}
```

Use the date format `YYYY-MM-DD` for the date of birth.

## Implementation Notes

- Database operations use Psycopg and direct SQL queries.
- SQL parameters are passed separately from query strings.
- Pydantic validates incoming request data.
- The PUT endpoint expects all required person fields.
- This is a learning project. Authentication and authorization are not implemented.
